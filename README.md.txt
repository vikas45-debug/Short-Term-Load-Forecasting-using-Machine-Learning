# Short Term Load Forecasting using Machine Learning

## Overview
This project predicts short-term electrical load using Machine Learning models.

## Models Used
- Random Forest
- SVR
- CatBoost

## Features
- Time features
- Lag features
- Rolling statistics
- Cyclical encoding

## Exploratory Data Analysis
Includes:
- Load distribution
- Correlation heatmap
- ACF plots
- Temperature vs Load analysis

## Project Structure
- Data
- preprocessing
- Models
- plots
- Trained_models

## Technologies Used
- Python
- Pandas

- Scikit-learn
- CatBoost
